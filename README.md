# ChatGPT学生认证提链 作者Rhys&5.6 Sol

一个轻量的 Chrome 扩展，用于从当前页面快速提取 ChatGPT 学生认证流程中的动态链接。

## 功能

- 提取当前页面 URL
- 识别 ChatGPT 学生验证页中的 iframe 验证链接
- 一键复制链接
- 不填写姓名、出生日期、学校或邮箱
- 不保存、不上传页面链接和认证信息

## 安装

1. 下载并解压本项目。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的项目文件夹。

## 使用

1. 打开 ChatGPT 学生验证页或 SheerID 学生认证页。
2. 点击 Chrome 工具栏中的本扩展图标。
3. 在弹出窗口中点击目标链接旁的“复制”。

认证链接包含动态参数，请以当前页面实时提取的结果为准，不要长期保存或公开分享带有个人账户标识的完整链接。

## 权限说明

本扩展只申请以下权限：

- `activeTab`：在用户主动点击扩展后读取当前标签页。
- `scripting`：读取当前页面中可见的 iframe 地址。

扩展不会访问浏览历史、Cookie、密码、Local Storage，也不会向外部服务器发送数据。

## 项目结构

```text
manifest.json  扩展配置
popup.html     弹出窗口结构
popup.css      弹出窗口样式
popup.js       链接提取与复制逻辑
```
